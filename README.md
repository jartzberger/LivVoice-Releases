# LivVoice by LivOrigin

**Your own AI voice engine.** Clone your voice, design brand-new voices, and narrate with word-perfect timing, all running free on your own NVIDIA graphics card.

## Download

👉 **[Get the latest LivVoice](https://github.com/jartzberger/LivVoice-Releases/releases/latest)**: download `LivVoice-Setup.exe` and double-click it. If Windows says "Windows protected your PC", click **More info → Run anyway**.

- **The first time it opens**, LivVoice sets itself up for your graphics card (about 10–15 minutes, ~6 GB). Keep the window open.
- LivVoice updates itself: open it and press **Update now** when a new version is ready.

Needs Windows 10/11. Works best with an NVIDIA RTX graphics card; without one it runs, slowly, on the processor.
